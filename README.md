# Gesture FX

Однофайловый оверлей для OBS: распознаёт жесты рук через MediaPipe и запускает эффекты
(конфетти, эмодзи, салют, молния, надписи…) или действия в OBS через obs-websocket.

Запуск: открыть `gesture-fx.html` в браузере или добавить как источник «Браузер» в OBS.
Подробная инструкция — внутри, вкладка «Настройки».
