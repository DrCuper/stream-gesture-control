# Gesture FX

Оверлей для стрима в одном HTML-файле. Распознаёт жесты рук через MediaPipe (а по желанию —
лицо и позу тела) и по правилам «жест → эффект» рисует конфетти, огонь в ладони, молнии между
руками, лазеры из глаз, надписи на прозрачном фоне или управляет OBS через obs-websocket.
Рука работает и как ручка: щепотка → зум, высота руки → громкость. Эмоуты из чата летают по
экрану, их можно отбивать и ловить. Никакой установки: открыл файл — работает.

- **Файл:** `gesture-fx.html` — весь код, стили и данные внутри.
- **Нужно:** OBS 28+ (встроенный WebSocket-сервер) или Chrome/Edge, интернет при первом
  запуске (модель и библиотека MediaPipe грузятся с CDN).
- **Не нужно:** сервер, Node, расширения, доступ браузера к камере (в режиме OBS).

## Быстрый старт

### Вариант 1. В OBS (основной)

1. В OBS: **Сервис → Настройки сервера WebSocket → Включить сервер WebSocket**. Порт по
   умолчанию `4455`. Если включена аутентификация, пароль смотри в «Показать сведения о подключении».
2. Камера остаётся обычным источником в OBS (например, с именем `cam`).
3. Добавь источник **Браузер**:
   - «Локальный файл» → `gesture-fx.html`, размер **1920×1080**;
   - чтобы спрятать интерфейс в эфире, сними галочку «Локальный файл» и укажи URL вида
     `file:///C:/путь/gesture-fx.html?obs`;
   - включи **«Управлять аудио через OBS»**, если хочешь звуки эффектов в стриме.
4. Положи источник «Браузер» **поверх камеры, с тем же размером и положением** — иначе эффекты
   не попадут в руки.
5. ПКМ по источнику → **Взаимодействовать**, нажми **H** — откроется панель. Вкладка
   **Настройки**:
   - «Источник кадров» → **Источник OBS (через WebSocket)**;
   - «Источник в OBS» → имя камеры (`cam`); после подключения имена подсказываются списком;
   - если OBS просит пароль, появится поле — впиши.
6. В левом верхнем углу HUD покажет `OBS ✓` и число рук. Покажи камере 👍 — полетит конфетти.

Кадры для распознавания берутся скриншотами из OBS, поэтому браузерному источнику не нужен
доступ к камере и флаг `--enable-media-stream`.

### Вариант 2. В браузере

Открой `gesture-fx.html` в Chrome или Edge, нажми **H** → **Настройки → Источник кадров →
Камера (доступ из браузера)**, разреши доступ. Картинка зеркалится автоматически. Этот режим
удобен для настройки правил и записи своих жестов без OBS.

Если этот же режим нужен внутри OBS, запускай OBS с флагом `--enable-media-stream` и закрой
другие программы, которые держат камеру.

## Как это устроено

```
кадры (OBS-скриншоты или камера)
   → MediaPipe Gesture Recognizer (до 2 рук) [+ Face Landmarker] [+ Pose Landmarker]
   → позы: встроенные + свои (k-NN) + двуручные + лицо + тело
   → движения: свайпы, круги, бросок, кивок; комбо «жест → жест»
   → правила: стабильность → удержание → кулдаун → срабатывание
   → ручки: значение (щепотка, высота, поворот…) → зум / громкость / фильтр OBS / оттенок
   → эффекты на canvas поверх прозрачного фона  /  команды в OBS  /  физика эмоутов
```

Всё состояние (правила, свои жесты, настройки) хранится в `localStorage` браузера под ключом
`gesturefx.config.v1`. В OBS это профиль браузерного источника, в Chrome — профиль пользователя.
Перенос между ними — через «Экспорт / импорт».

## Интерфейс

| Действие | Как |
|---|---|
| Открыть/закрыть панель | ⚙ в правом верхнем углу или клавиша **H** (работает и в русской раскладке) |

## Жесты

### Позы руки

| Жест | Идентификатор | Откуда |
|---|---|---|
| 👍 Палец вверх | `Thumb_Up` | MediaPipe |
| 👎 Палец вниз | `Thumb_Down` | MediaPipe |
| ✌️ Виктори | `Victory` | MediaPipe |
| ✋ Ладонь | `Open_Palm` | MediaPipe |
| ✊ Кулак | `Closed_Fist` | MediaPipe |
| ☝️ Указательный вверх | `Pointing_Up` | MediaPipe |
| 🤟 Я тебя люблю | `ILoveYou` | MediaPipe |
| 🫰 Сердечко пальцами | `Finger_Heart` | своя геометрия по ландмаркам |
| 🫶 Сердце двумя руками | `Two_Hand_Heart` | своя геометрия, нужны обе руки |

Жесты распознаются **на обеих руках одновременно**:

- разные жесты на разных руках запускают каждый свои правила;
- одинаковый жест двумя руками даёт **два срабатывания** у эффектов, привязанных к руке
  (конфетти, сердечки, реакция, взрыв, молния, шлейф, зум) — по одному из каждой руки;
- экранные эффекты (салют, вспышка, надпись…) и действия OBS срабатывают один раз;
- в карточке правила это регулируется галочкой **«с каждой руки отдельно»**.

Порог уверенности для встроенных жестов — ползунок **«Уверенность»** в настройках
(по умолчанию 0.60). Ложные срабатывания — поднимай, не ловит — опускай. Ещё одна защита —
**«Стабильность»**: поза должна быть видна N детекций подряд (по умолчанию 1), прежде чем
считаться активной.

### Движения

Движения — **события**: срабатывают в момент, когда движение закончилось, «удержание» в правиле
для них не используется, кулдаун работает как обычно. Распознаются по траектории центра ладони
за последние 0,5–1,5 с.

| Жест | Идентификатор | Как |
|---|---|---|
| 👈 👉 👆 👇 Свайп | `Swipe_Left` `Swipe_Right` `Swipe_Up` `Swipe_Down` | быстрое движение почти по прямой (все отрезки в одну сторону ±35°) на 22 % ширины экрана за 0,5 с |
| 🔃 🔄 Круг | `Circle_CW` `Circle_CCW` | почти полный оборот за 1,4 с; направление — как видит зритель |
| 🤾 Бросок | `Throw` | сжал кулак → резко двинул рукой → раскрыл ладонь. Событие несёт направление: **Фаерболл** летит туда, куда бросил |
| ↕️ Кивок, ↔️ Мотание | `Face_Nod` `Face_Shake` | нос колеблется по вертикали/горизонтали, не меньше трёх смен направления за 1,2 с (нужна модель лица) |

Настройки → **Движения**: путь и время свайпа, время круга, скорость броска. После каждого
события на этой руке 0,7–1 с новые движения не ловятся, чтобы одно движение не дало два события.

### Лицо

Включается в Настройки → **Лицо и тело → Модель лица** (грузится из интернета, ещё одна
нейросеть на кадр). Жесты считаются по blendshapes MediaPipe, порог — ползунок
**«Чувствительность»**.

| Жест | Идентификатор |
|---|---|
| 😮 Открытый рот | `Face_MouthOpen` |
| 😁 Улыбка | `Face_Smile` |
| 🤨 Поднятые брови | `Face_BrowsUp` |
| 😠 Нахмуренные брови | `Face_Frown` |
| 😉 Подмигивание | `Face_Wink` |
| 😘 Губы трубочкой | `Face_Kiss` |
| 🐡 Надутые щёки | `Face_Puff` |
| 🤦 Фейспалм | `Facepalm` — центр ладони внутри рамки лица; работает и от модели позы |

Лицо считается «рукой» `F`: эффекты, привязанные к руке (лазеры из глаз, реакция, сердечки),
стартуют из центра лица.

### Тело

Настройки → **Лицо и тело → Модель позы**. Жесты по 33 точкам тела, порог — **«Чувствительность»**.

| Жест | Идентификатор | Условие |
|---|---|---|
| 🤷 Пожать плечами | `Pose_Shrug` | плечи подтянулись к ушам |
| 🙅 Скрещённые руки | `Pose_ArmsCrossed` | кисти накрест на уровне груди |
| 🙌 Руки вверх | `Pose_HandsUp` | обе кисти выше носа |
| 🤸 Руки в стороны | `Pose_TPose` | кисти на уровне плеч, далеко от них |

Обе модели можно считать реже рук (**«Считать лицо/тело: каждый 2-й кадр»**), чтобы снизить
нагрузку. В HUD видно `лицо ✓` / `тело ✓`, когда модель загружена и видит тебя.

### Свои жесты: обучение по примеру

Вкладка **Жесты**. Жест — набор записанных поз руки (нормализованные координаты 21 точки),
текущая поза сравнивается с ними по среднему расстоянию, без ручных правил.

Два способа записать:

- **● Записать** — 3 секунды на подготовку, затем 2,5 секунды кадров подряд. Держи жест и
  **слегка поворачивай руку** — так он устойчивее к ракурсу. На медленной машине запись
  продлевается, пока не наберётся хотя бы 15 кадров.
- **📸 Кадр** или клавиша **C** — один кадр за нажатие: показал жест, нажал, показал в другом
  положении, нажал — 10–20 раз. Кадры копятся в один жест, пока не сменишь название
  (Enter в поле названия убирает фокус, чтобы C заработала).

Кнопка **«+ кадры»** / **📸** в карточке добавляет кадры к готовому жесту, **«→ в правило»**
создаёт правило с ним.

Распознавание:

- **Порог** — насколько строго сравнивать (по умолчанию 0.25 для одной руки, 0.35 для двух).
- **«сейчас: 0.18»** и полоска **«Похожесть»** — живое расстояние до ближайшего кадра;
  зелёное — жест активен. Это главный инструмент подбора порога.
- **k-NN** (Настройки → Распознавание, включено): среди всех кадров всех своих жестов берутся
  5 ближайших, они голосуют с весом 1/расстояние, срабатывает один победитель — и только если
  его ближайший кадр ближе порога. Так похожие жесты не срабатывают вместе. Выключишь —
  каждый жест сравнивается со своим порогом независимо.
- **🚫 Записать фон (не жест)** — запиши обычные позы рук: как ты держишь микрофон, чешешь
  голову, лежишь на мышке. «Фон» участвует в голосовании, но сам никогда не срабатывает:
  если текущая поза ближе к фону, чем к жесту, — тишина. Это главная защита от ложняков
  у своих жестов.
- Левая и правая рука зеркалятся при расчёте, поэтому жест, записанный правой рукой, работает и левой.
- **«Свои жесты важнее встроенных»**: если на руке одновременно узнан свой и встроенный жест,
  срабатывает только свой.

### Комбо: жесты подряд

Внизу вкладки **Жесты**. Цепочка из 2–3 жестов одной рукой (или подряд на лице) с заданным
максимальным промежутком между шагами, например ✊ → ✋ или ✋ → 👉 свайп. Шагом может быть
любой встроенный жест, движение или свой жест. Комбо — событие: срабатывает в момент появления
последнего шага, без удержания; в правилах выбирается как 🔗.

## Правила

Правило — это «жест → эффект» с настройками. На один жест можно повесить сколько угодно правил
(например, ✊ запускает молнию и тряску одновременно).

| Поле | Что значит | По умолчанию |
|---|---|---|
| Жест | встроенный или свой | — |
| Эффект | из списка ниже | — |
| Параметры | зависят от эффекта | значения эффекта |
| Звук | синтезированный звук при срабатывании: поп, дзынь, бум, вжух, разряд, без звука | у каждого эффекта свой |
| Удержание, мс | сколько держать жест до срабатывания; для событий (движения, кивок, комбо) не используется | 350 |
| Кулдаун, мс | пауза до следующего срабатывания | 2500 |
| Повторять, пока держу жест | иначе одно срабатывание на одно удержание | выкл |
| С каждой руки отдельно | показывается только у эффектов, привязанных к руке | вкл |

Детекция может моргать: потеря жеста короче 220 мс не сбрасывает удержание.

Удержание разной длины — разные действия: два правила на один жест с удержанием 500 и 3000 мс
дадут лёгкий эффект сразу и тяжёлый через три секунды. Эффекты «пока держу» (огонь в ладони,
искры, шар, молния между руками, лазеры) живут, пока жест активен, и гаснут при отпускании —
«Повторять» им не нужно.

Кнопка **▶** в карточке запускает эффект из центра экрана, не дожидаясь жеста.

## Ручки: рука как регулятор

Вкладка **Ручки**. Ручка — не триггер, а непрерывный параметр: пока выполняется **условие**
(выбранный жест на руке или просто рука/лицо в кадре), **источник** линейно переводится из
диапазона входа в диапазон **цели**. Отпустил — значение либо возвращается к заданному, либо
остаётся.

| Источник | Что измеряет | Диапазон по умолчанию |
|---|---|---|
| Щепотка | зазор большой–указательный в размерах ладони | 0.15–1.3 |
| Раскрытие ладони | среднее расстояние кончиков пальцев от запястья | 1.0–1.9 |
| Поворот кисти | угол запястье→середина ладони на экране, 0° — пальцы вверх | −90…90° |
| Высота руки / по горизонтали | центр ладони в долях экрана | 15–85 % |
| Близость к камере | размер ладони в долях высоты кадра | 8–40 % |
| Время удержания жеста | секунды с момента, как жест-условие стал активен — «заряд» | 0–3 с |
| Расстояние между руками | между центрами ладоней, в долях ширины | 10–80 % |
| Открытость рта, брови, наклон и положение головы | модель лица | |

| Цель | Что делает |
|---|---|
| Зум картинки в оверлее | масштаб камеры в режиме «Камера (доступ из браузера)», вокруг руки или центра |
| OBS: трансформация источника | масштаб вокруг видимого центра, поворот, сдвиг по X/Y — считается от положения источника в момент включения ручки |
| OBS: громкость источника звука | множитель 0–1 |
| OBS: параметр фильтра | любая числовая настройка фильтра по ключу (например `blur_amount`) |
| Громкость эффектов оверлея | множитель к звукам |
| Интенсивность эффектов | множитель к количеству частиц у всех эффектов этого оверлея |
| Оттенок эффектов | `hue-rotate` всех эффектов и картинок оверлея |

Ещё: рука (любая / левая / правая в кадре), **«наоборот»** (инверсия входа), **плавность**
(сглаживание), **«Отпустил → вернуть к значению / оставить»**. Живое значение источника и
выхода видно в карточке, в HUD и в отладочном слое. Кнопки **пресетов** внизу: «Щепотка →
зум камеры в OBS», «Высота ✋ → громкость OBS», «Поворот ✋ → оттенок», «Удержание ✊ →
интенсивность», «Открытый рот → зум оверлея».

Команды в OBS уходят не чаще 14 раз в секунду и только при заметном изменении; после ошибки
(нет такого источника) ручка молчит 3 секунды и пробует снова.

## Эффекты

Привязанные к руке (🖐) стартуют из точки, где рука на экране, и срабатывают с каждой руки
отдельно. Эффекты «пока держу» (⏳) следят за рукой и живут, пока жест активен (или не дольше
«Не дольше, с»). Остальные — на весь экран.

| Эффект | | Параметры | Звук |
|---|---|---|---|
| 🎉 Конфетти | 🖐 | количество (160), откуда: от руки / сверху | поп |
| 💖 Сердечки | 🖐 | эмодзи (❤️), количество (30) | поп |
| 😍 Эмодзи-реакция | 🖐 | эмодзи (😍 🔥 👏 — случайный из списка), размер px (150), длительность (1.5 с) | поп |
| 🌧️ Дождь эмодзи | | эмодзи (💀), количество (45), длительность (2.5 с) | вжух |
| 🎆 Салют | | залпов (5) | бум |
| 💥 Взрыв частиц | 🖐 | цвет, количество (130) | вжух |
| 🟪 Неон-рамка | | цвет, длительность (3 с) | дзынь |
| ⚡ Вспышка | | цвет, длительность (0.4 с) | — |
| 🔤 Надпись | | текст (GG!), цвет, длительность (2.5 с) | дзынь |
| 📺 Глитч | | длительность (1.2 с) | разряд |
| 🫨 Тряска | | сила px (22), длительность (0.6 с) | бум |
| 🔍 Зум-удар | 🖐 | сила 0–1 (0.35), длительность (0.8 с) | вжух |

### Картинки, GIF и видео

Эффект **«Картинка / GIF / видео»** показывает файл поверх всего на заданное время. Форматы:
PNG, JPG, GIF, WebP, APNG, а также WebM и MP4 (видео играет без звука, по кругу; WebM с
альфа-каналом даёт прозрачный фон).

Откуда берётся файл — поле **«Файл»** в правиле:

| Способ | Как | Когда удобно |
|---|---|---|
| Загрузить с диска | кнопка **📁** в правиле или **Библиотека → Медиа → Загрузить файлы**; файл сохраняется в браузере (IndexedDB) и появляется в выпадающем списке | быстро, без возни с путями |
| Путь рядом с html | «ссылка или путь…» → `img/pog.gif` — относительно папки, где лежит `gesture-fx.html` | переносимый конфиг: папку с html и картинками можно копировать целиком |
| Ссылка | `https://…/emote.gif` — прямой адрес файла | эмоуты 7TV/BTTV, Tenor, свой хостинг |

Нюансы:

- Загруженные файлы живут в профиле этого браузера (в OBS — в профиле источника «Браузер»)
  и **в экспорт конфига не попадают**. Правило на другой машине увидит «(файл удалён)».
- GIF каждый раз стартует с первого кадра, даже если та же картинка уже на экране.
- «Следовать за рукой» работает при «Где: у руки»: картинка едет за ладонью, пока показана.
  Так делаются шапки, очки, маски на руку.
- Картинки, которые используются в правилах, подгружаются заранее, чтобы первый показ не
  запаздывал. Ссылки в интернет всё равно зависят от сети: для эфира надёжнее локальные файлы.
- Тряска экрана трясёт и картинки; глитч и зум-удар на них не действуют (они рисуются
  отдельным слоем, а не на canvas).

В **Библиотека → Медиа** все загруженные файлы: превью, размер, «▶» для проверки,
«+ правило» и удаление.

### Поля «Эмодзи»

Поддерживается **весь стандартный набор эмодзи** (Unicode 16.0), включая составные:
семьи 👨‍👩‍👧, флаги 🇷🇺 и 🏴‍☠️, оттенки кожи 👍🏽, клавиши 1️⃣, пары вроде ❤️‍🔥.

- Эмодзи можно писать подряд, без пробелов: `😀🔥💀` — три разных эмодзи.
- Под полем показаны **фишки**: как именно строка разобрана. Клик по фишке убирает её.
- Обычные слова тоже работают (`GG WP` — два «эмодзи» текстом).
- Кнопка **😀** открывает пикер: 9 групп, переключатель оттенка кожи ✋🏻…✋🏿 (запоминается
  в настройках). Эмодзи, которые шрифт этой машины не умеет рисовать, пикер прячет и пишет
  сколько скрыл. На Windows 10 это, например, флаги стран и самые новые эмодзи.

Эмодзи рисуются системным шрифтом (Segoe UI Emoji / Apple Color Emoji / Noto Color Emoji),
поэтому в OBS на Windows и в Chrome на Mac они выглядят по-разному — это нормально.

## Физика и чат

Настройки → **Физика и чат**. Эмоуты и эмодзи — тела с массой: летают по экрану, отскакивают
от краёв, живут заданное время. Ладонь — круглый коллайдер со скоростью:

- **открытой рукой** отбиваешь (вылетают искры, если ударил быстро);
- **кулаком** или **щепоткой** ловишь — тело лопается, рядом всплывает «+1», счёт виден в HUD.

| Настройка | По умолчанию |
|---|---|
| Гравитация | 0 — парят; 1 — падают и прыгают по полу |
| Размер, px / Живут, с / Не больше | 72 / 14 / 60 |
| Упругость | 0.8 |
| Ловить кулаком | вкл (щепоткой — всегда) |

Откуда берутся тела:

- **Twitch-канал** — имя канала или ссылка. Чат читается анонимно (IRC без токена): стандартные
  эмоуты Twitch грузятся с CDN, эмодзи берутся из текста сообщений, не больше N на сообщение.
  Эмоуты 7TV/BTTV/FFZ не распознаются. Статус — рядом с полем и в HUD (`чат ✓`).
- эффект **«Выпустить эмоуты»** в правиле — свои эмодзи из руки по жесту;
- кнопка **«▶ выпустить 5»** для проверки, `GFX.spawn('🔥')` в консоли.

## Управление OBS

Работает через obs-websocket **v5** (встроен в OBS 28+). Настройки → **OBS WebSocket**:

| Настройка | По умолчанию |
|---|---|
| Подключаться к OBS | вкл |
| Адрес | `ws://127.0.0.1:4455` |
| Пароль | поле появляется, когда OBS требует аутентификацию |

Статус виден рядом с галочкой и в HUD (`OBS ✓` / `OBS ✗`). При обрыве соединение
восстанавливается каждые 5 секунд. После подключения в полях правил появляются подсказки со
списком сцен, источников и аудиовходов.

### Действия

| Эффект | Параметры | Примечания |
|---|---|---|
| 🎬 OBS: сменить сцену | сцена; вернуть через N с (0 — не возвращать) | возвращает на ту сцену, что была до переключения |
| 👁️ OBS: показать/скрыть источник | источник; сцена (пусто — текущая); действие: показать на время / переключить / показать / скрыть; длительность (4 с) | ищет элемент на верхнем уровне сцены, внутри групп не найдёт |
| 🔇 OBS: звук вкл/выкл | источник звука; действие: переключить / выключить / включить | |
| 🎛️ OBS: фильтр вкл/выкл | источник; фильтр; действие: включить на время / переключить / включить / выключить; длительность (3 с) | |
| ⏺️ OBS: сохранить повтор | — | нужен включённый буфер повтора |

Ошибки OBS («нет такого источника», «не подключён») показываются всплывашкой внизу, когда
открыта панель; в режиме `?obs` при закрытой панели — только в консоль.

### Ограничения

- Приложение не подписано на события OBS: если ты сам переключил сцену, оно об этом не узнает;
  списки сцен обновляются только при подключении.
- Нет управления записью, стримом, медиа-источниками, текстом и горячими клавишами.
- Пароль хранится в `localStorage` открытым текстом и **не попадает в экспорт**.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| «Не удалось загрузить модель MediaPipe» | нужен интернет к `cdn.jsdelivr.net` и `storage.googleapis.com`; корпоративный прокси или блокировщик могут резать |
| «Не получаю кадры из OBS» | имя источника точь-в-точь как в OBS; WebSocket-сервер включён; пароль верный |
| `OBS ✗` не меняется на ✓ | OBS запущен? порт 4455 не занят? адрес `ws://`, не `http://` |
| «Нет доступа к камере» | в браузере — разрешить и закрыть программы, держащие камеру; в OBS — флаг `--enable-media-stream` или переключись на источник OBS |
| Эффекты не в руках, а в стороне | источник «Браузер» должен совпадать с камерой по размеру и положению; в режиме камеры проверь зеркалирование |
| Жест не ловится | рука целиком в кадре, нормальный свет; опусти «Уверенность»; для сложных жестов запиши свой |
| Эффект срабатывает дважды | это две руки: сними «с каждой руки отдельно» или подними кулдаун |
| Свой жест срабатывает от обычного положения руки | запиши «фон» с этими позами; уменьши порог; включи k-NN |
| Свайп ловится, когда просто машу рукой | подними «Свайп: путь»; свайп ловится только по прямой, дуги и круги — нет |
| Круг не ловится | веди ладонь по кругу диаметром не меньше четверти экрана за секунду, не отрывая; смотри траекторию в отладке |
| Бросок не ловится | сначала чётко кулак, потом резкое движение с раскрытием ладони; снизь «Бросок: скорость» |
| `лицо —` / `тело —` в HUD | модель загружена, но не видит: лицо целиком в кадре, свет; для позы нужны плечи и кисти |
| Ручка «OBS: трансформация» не двигает источник | имя источника точь-в-точь как в OBS; сцена указана или текущая; источник не внутри группы |
| `чат ✗` | канал без `#` и без лишнего; интернет; Twitch иногда рвёт соединение — переподключение раз в 5 с |
| FPS просел после включения лица/позы | «Считать лицо/тело: каждый 2-й/3-й кадр»; включай по одной модели; GPU |
| Эмодзи рисуются квадратиками | шрифт системы их не знает; выбирай из пикера — он показывает только то, что рендерится |
| Низкий FPS | снизь «Кадров/с» и ширину скриншота; включи GPU; уменьши «Количество» у частиц |
| Настройки пропали после переустановки OBS | они жили в профиле браузерного источника — сохраняй экспорт файлом |

## Для разработчиков

Файл один, но внутри он разбит на секции с заголовками-комментариями:
`Константы → Утилиты → Эмодзи → Медиа → Эффекты → Звук → OBS WebSocket → Конфиг → Признаки руки →
Камера и модель → Распознавание (треки, динамика, лицо, тело, k-NN, computeActive) → Правила →
Запись своих жестов → Ручки → Физика → Twitch-чат → Рендер → HUD → UI → Старт`.

### Добавить эффект

Один объект в `EFFECTS`:

```js
sparkle:{name:'Искры',icon:'✨',sound:'chime',anchored:true,
  params:{color:P.color('#ffffff'), count:P.count(50)},
  run(p, a, src){
    // p   — параметры с учётом дефолтов
    // a   — {x,y} точка руки на экране (или центр экрана при тесте)
    // src — ключ для tips.get(): 'Thumb_Up@L' и т.п., чтобы следить за пальцем этой руки
    for(let i=0;i<p.count;i++) fx.push(particle({kind:'dot',x:a.x,y:a.y,vx:rnd(-300,300),vy:rnd(-300,300),
      drag:2,life:1,r:3,color:p.color,shrink:true}));
  }},
```

- `anchored:true` — эффект привязан к руке и будет срабатывать с каждой руки отдельно;
  `twoHands:true` — один запуск на обе руки; `held:true` — подпись «живёт, пока держу».
- `a.dir` — направление события (есть у `Throw` и свайпов), в долях ширины экрана.
- Эффект «пока держу»: `fx.push(heldEntity(src, maxSec, draw, update))` — живёт, пока
  `isHeld(src)`, потом гаснет (`this.fade` 1→0). Живая рука — `handOf(src)` →
  `{pts, c, sc, vx, vy, m:{pinch,spread,roll}}`; лицо — `faceNow` (`pts[468]`/`pts[473]` —
  зрачки, `box`, `bs` blendshapes); тело — `poseNow`. `knobState.intensity` — ручка интенсивности.
- `obs:true` — помечает действие OBS (только для подписи).
- Типы параметров: `number`, `color`, `text`, `select` (`options:{key:label}`), `bool`
  (чекбокс, подпись в `text`), `emoji` (поле с пикером; разбирай значение через
  `emojiTokens(str, fallback)`), `media` (файл; `mediaResolve(ref)` даёт `{url, blob?, video}`,
  `mediaEl(m, true)` — готовый `<img>`/`<video>` для показа).
- Частицы — `particle({...})` с видами рисования `confetti`, `emoji`, `dot`, `spark` (см. `DRAW`);
  произвольная анимация — `entity(life, draw, update)`. Если сущность держит DOM-элемент (как
  картинки в слое `#media`), задай ей `dispose()` — цикл вызовет его при удалении.
- Картинки и видео не рисуются на canvas (у GIF он берёт только первый кадр), а живут
  DOM-элементами в `#media`; загруженные файлы — в IndexedDB `gesturefx/media`, ссылка на них
  в правиле — `media:<id>`.
- Эффект появится в Библиотеке и в списке правил сам.

### Жесты, события, ручки

- Каталог встроенных жестов — `BUILTIN` с полями `group` (`hand` / `dyn` / `face` / `pose`) и
  `event:true` для одноразовых событий. Событие живёт 300 мс в `activeNow`, правила для него
  игнорируют `hold`.
- `computeActive(t)` отдаёт `Map(gestureId → [{hand, anchor, tip, score, dir?, event?}])`.
  Руки — `L`/`R`, две руки — `LR`, лицо — `F`, тело — `P`. Стабильность, события, комбо и
  k-NN считаются внутри.
- Движения — `detectDynamics(t)` по `tracks` (центр ладони в долях экрана за 2 с), события —
  `emitEvent(id, hand, anchor, tip, {dir, refr}, t)`.
- Ручки — `KNOB_SRC` (источники) и `KNOB_TGT` (цели); новая цель — объект с `min/max/reset`,
  `obs:true` + ветка в `knobApply`, иначе — ветка в `processKnobs`.
- Физика — `physSpawn({ch|url, x, y, vx, vy, size})`, тела в `phys.bodies`.

### Консоль

В `window.GFX` вынесены удобные ручки:

```js
GFX.fire('reaction', {emoji:'🔥'}, {x:400,y:400})  // запустить эффект без жеста
GFX.fire('fireball', {}, {x:400,y:400,dir:{x:1,y:-0.3}})  // с направлением
GFX.emojiTokens('👨‍👩‍👧🇷🇺 GG')                     // ['👨‍👩‍👧','🇷🇺','GG']
GFX.cfg()                                           // текущий конфиг (живой объект)
GFX.spawn('🔥', {x:300, y:300})                     // тело в физику
GFX.chat('@emotes=25:0-4 :a!a@a PRIVMSG #c :Kappa 😂') // как будто пришло из Twitch
GFX.knobState                                       // текущие значения ручек
```

Для автотестов есть `GFX._test.frame(result, t, w, h)` — подать результат модели рук напрямую,
`GFX._test.face(result, t)` и `GFX._test.pose(result, t)` — лица и позы.

### Данные и зависимости

- MediaPipe Tasks Vision `1.2.0` с jsDelivr, модели `gesture_recognizer.task`,
  `face_landmarker.task` (478 точек + 52 blendshapes) и `pose_landmarker_lite.task` (float16) из
  `storage.googleapis.com/mediapipe-models`. Версии — константы в начале скрипта. Лицо и поза
  грузятся только при включении в настройках.
- Twitch: `wss://irc-ws.chat.twitch.tv` анонимно (`justinfan…`), эмоуты —
  `static-cdn.jtvnw.net/emoticons/v2/<id>/default/dark/3.0`.
- Список эмодзи сгенерирован из `emoji-test.txt` Unicode 16.0: только `fully-qualified`,
  без вариантов оттенков кожи (они получаются на лету) — 1906 эмодзи в 9 группах.
- obs-websocket v5: авторизация `SHA-256(base64(SHA-256(password+salt)) + challenge)`;
  есть запасная реализация SHA-256 на случай `crypto.subtle` недоступен (http, а не https/file).
